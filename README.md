# API de Gerenciamento de Tarefas

API REST desenvolvida em Python para gerenciamento de tarefas.

## 📌 Funcionalidades

- Criar tarefas
- Listar tarefas
- Atualizar tarefas
- Deletar tarefas
- Marcar tarefas como concluídas

## 🛠 Tecnologias utilizadas

- Python
- Flask
- SQLite

## 📡 Rotas da API

POST /tarefas → criar tarefa  
GET /tarefas → listar tarefas  
GET /tarefas/{id} → buscar tarefa  
PUT /tarefas/{id} → atualizar tarefa  
DELETE /tarefas/{id} → deletar tarefa

## 🎯 Objetivo do projeto

Praticar desenvolvimento de APIs REST utilizando Python e manipulação de dados em banco de dados.

## 🚀 Aprendizados

- Desenvolvimento de API REST
- Estrutura de backend
- Manipulação de banco de dados# task-api-python
